# Omega-Gerenciamento-de-Estudos
Usando o Claude Sonnet 5.5, criei um aplicativo para gerenciar estudos que, na minha opinião, é o melhor que tem.
Acredito que a maioria das funcionalidades que um concurseiro ou vestibulando precisa se encontram aqui!
O aplicativo é totalmente gratuito, e sempre vai ser :)

Funcionalidades
- Página de Foco: é possível escolher entre cronômetro, temporizador e pomodoro, além de poder importar suas músicas favoritas e criar playlists
- Lista de Tarefas: crie várias listas para adicionar suas tarefas, adicionando prazos, subtarefas, matérias / tags etc
- Página de Edital: adicione todos os pontos do edital do seu concurso e classifique seu desempenho em cada um (ruim, mediano, bom) para conseguir entender em que áreas você precisa melhorar
- Calendário: crie eventos para não se esquecer do dia e horário do vestibular / concurso, limites de inscrição etc
- Cronograma: para quem gosta de trabalhar com cronogramas de estudo, essa página ajuda muito na sua organização, também é possível criar mais de um cronograma se preciso. Para quem prefere se organizar com ciclo de estudos, também temos essa opção!
- Simulados / Redações: um diário para adicionar seus simulados e redações, ver onde você está indo bem ou mal e também observar o progresso feito ao longo de seus estudos :)
-  Personalização: escolha a cor que mais lhe agrada, além de poder escolher entre modo claro e escuro!

Para instalar:
- Windows: inicie "build-windows"
- MacOS / Linux: inicie "build_mac_linux"

Boa sorte em seus estudos!!
